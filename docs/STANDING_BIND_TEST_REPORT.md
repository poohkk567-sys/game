# ผลตรวจนินจายืนดึงโซ่

ตรวจบนLinux ด้วย Godot4.2.2 และ4.6.3 ภาพจริงใช้OpenGL Compatibility / Mesa llvmpipe

## ระบบเกมและการไม่ถูกบัง

- Godot4.6.3: `bash tools/check.sh` ผ่าน25ชุด / **1,762ข้อ / 0ล้มเหลว**
- Godot4.2.2: Standing Bind70 + Ninja Arrivals94 + Side Guardian64 + Demon Bind55 = **283ข้อ / 0ล้มเหลว**
- ชุดStanding BindตรวจตัวPHUZASHIเดิม/CHILL ทั้งสองทิศและสองระดับบัฟ นินจาทั้งตัวอยู่แยกจากกรอบร่างเป้าหมายกลางสนามครบ8เฟรม ไม่ตรวจแค่ตาหรือจุดหน้ากากอย่างรุ่นก่อน
- ตรวจลำดับวาดนินจาสูงกว่าร่างเป้าหมาย และโซ่ด้านหน้าสูงกว่านินจา มีโซ่ขณะHOLDจริง ค่า25MP/ไม่ทำดาเมจ/ขนาด100–116px/ล็อค0.7–1.1วินาทีคงเดิม
- ตรวจใกล้ขอบซ้าย75px/ขวา1205px นินจาทั้ง8เฟรมถูกจัดให้อยู่ในช่วง12..1268px ไม่หลุดจอหรือถูกเป้าหมายวาดทับ เป้าหมายครอบคลุมBLACK COAT นักมวยและASSJIRO
- เมื่อปล่อยล็อค เริ่มยกใหม่หรือออกฉาก นินจาและโซ่หายพร้อมกัน เริ่มยก50MPเดิม

## ภาพจริงและชุดแจก

เรนเดอร์ครบชุดตัวละครและนินจา8เฟรมสองทิศ **1,112samples / 0ล้มเหลว ต่อรุ่น** ภาพไม่ว่างและไม่ถูกตัดด้วยviewport

บันทึกฉากจริงGodot4.2.2 ทั้งปกติ/บัฟ ซ้าย/ขวา และสองขอบสนาม6กรณี ที่1280×720/60fps จำนวน871เฟรม ประมาณ14.52วินาที ตรวจพบว่าโซ่ชุดแรกพาดสูงไปถึงหน้า จึงลดแนวโซ่ลง24pxให้รัดอก เอวและขา ขณะที่ยังเห็นหน้าเป้าหมาย

ZIPตรวจCRCและเทียบทุกไฟล์กับซอร์ส แตกใหม่ไม่มีแคช เข้าGodot4.2.2และทวนสี่ชุดข้างบนผ่าน **283ข้อ / 0ล้มเหลว** ดาวน์โหลดกลับจากGitHubและเทียบทุกไฟล์ตรงกับชุดที่ตรวจแล้ว

ไม่มีEXE/PCK/cache/วิดีโอหรือZIPเก่าซ้อนในชุดซอร์ส วิดีโอแยกบนGitHubเติมมานา100เฉพาะสาธิต การเล่นจริงเริ่ม50MP

การตรวจจอยใช้InputEventในGodot ไม่ใช่ฮาร์ดแวร์จอย/Windowsของผู้ใช้ ไม่มีการเปลี่ยนตัวละครหรือสกิลอื่นในรุ่นนี้
