# ผลตรวจโหมดทดลอง Co-op บอส3D

Godot4.2.2และ4.6.3 บนLinux ใช้OpenGL Compatibility / Mesa llvmpipeสำหรับการตรวจภาพจริง

## การทำงาน

ชุดตรวจรวม **28ชุด / 2,125ข้อ / 0ล้มเหลว ต่อรุ่น** แยกชุดเดิม27ชุด2,048ข้อและชุดใหม่Co-op77ข้อ ไม่มีSCRIPT ERROR/ERROR/FAILในผลสุดท้าย ชุดเดิม27ชุดยังทวนสกิล/ตัวละคร/มานา/การ์ด/จอย/คอมโบ/นินจา/ฟีโน่ตามเดิมครบ

ชุดCo-opตรวจตัวละครเป็นCharacterBody3Dจริง บอส/พื้น/กล้องเป็น3D และSprite3Dใช้AtlasTextureดั้งเดิมของPHUZASHI CHILLกับASSJIRO ไม่ปรับภาพต้นฉบับ

ครอบคลุมคอมโบสามหมัด34/สามเตะ52แยกทั้งสองตัว สองคนโจมตีบอสพร้อมกัน ตัวนับผลงาน ไม่มีfriendly fire ระยะลึก/ความสูงจริง ทิศโจมตีล็อกตอนเริ่ม กระโดดต่อย คีย์บอร์ดสองคน สติ๊กขึ้นเดินเข้าฉากไม่กระโดด deadzone ปุ่มจอยและปุ่มที่ตั้งใหม่ การ์ด/Perfect Guard/โล่โปร่งใส วงเตือน/กระโดดหลบ บอสกระโดดอย่างต่อเนื่อง การพุ่งโดนคนละหนึ่งครั้ง BREAK/Phase2 ชุบเพื่อน/ถูกขัด การล้มไม่ตกทะลุพื้น แพ้/ชนะ/เริ่มใหม่ พัก/ตั้งจอย กล้องร่วมกรอบปลอดHUD และเมนูเข้าออกโหมดจริง

ทวนAIบอสให้โจมตีวนสามรูปแบบจนชนะทีมที่ยืนนิ่ง โดยไม่สั่งดาเมจเทียม ยืนยันเกมจบและไม่มีบอสค้างในท่าเดิม

## ภาพและการแยกระบบ

ตรวจภาพพื้นฐาน13ท่า × 8ภาพ × 2ทิศ × 2ตัว = **416ตัวอย่าง ต่อรุ่น** บนSprite3DในSubViewportสามมิติ ภาพไม่ว่างและไม่ถูกขอบตัด คลิปGodot4.2.2จริง1280×720/60fps จำนวน1,164เฟรม ประมาณ19.4วินาที มีการจัดตำแหน่งและป้อนปุ่มเพื่อสาธิตเท่านั้น ไม่เพิ่มผู้เล่นAIในเกม Nativeบันทึกภาพหน้าเมนู สนาม คอมโบคู่ วงกวาด/กระโดดหลบ กระโดดทุบ แนวพุ่ง ชุบเพื่อน และช่วงสู้กับAIจริง

Godot4.2 dummy rendererมีปัญหาnull meshเมื่อคืนArrayMesh จึงใช้Nodeแสดงผลว่างสำหรับชิ้นตกแต่งในheadless4.2 และไม่สร้างเอฟเฟกต์ภาพ/เสียงบนheadless ทั้งสองรุ่นยังทดสอบCollisionShape3D/เวลา/AI/ดาเมจ/จอยด้วยphysicsจริง การตรวจภาพใช้native OpenGLที่สร้างgeometryและเอฟเฟกต์จริงครบ รวมถึงเงาและประกายที่ใช้MultiMesh

แยกตัวควบคุมCo-opออกจากCharacterBody2Dเดิม เพิ่มaliasการเดินลึก/กระโดด/ชุบเฉพาะcontextCOOP เมื่อออกจะคืนcontextVERSUS ไม่เขียนทับW/Upของโหมด2D และสกิล/มานา50เริ่มยกของเกมเดิมยังใช้ตามเดิม

## ชุดดาวน์โหลด

ชุดซอร์สGodotไม่มีEXE/PCK/cache/วิดีโอหรือZIPเก่าซ้อน ตรวจCRCและเทียบไฟล์กับซอร์สที่ทดสอบ ทวนเปิดจากZIPที่แตกใหม่ด้วยGodot4.2.2: Co-op77 + Gamepads54 + Controller Parity223 = **354ข้อ / 0ล้มเหลว** และดาวน์โหลดGitHubกลับมาเทียบทุกไฟล์ก่อนส่ง

จอยตรวจด้วยInputEventจริงในGodot ยังไม่ได้ตรวจจอยฮาร์ดแวร์บนWindowsของผู้ใช้ การทดสอบด้วยMesaซอฟต์แวร์ยืนยันภาพและการทำงาน ไม่ใช่ตัวเลขประสิทธิภาพGPUของเครื่องผู้ใช้ โหมดนี้เป็นlocalสองคนและยังไม่มีสกิลพิเศษ/ออนไลน์
