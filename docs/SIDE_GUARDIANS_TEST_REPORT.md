# ผลตรวจออร่าหันข้าง

Godot **4.2.2.stable** และ **4.6.3.stable** บนLinux; ภาพจริงใช้OpenGL Compatibility / Mesa llvmpipe

## ระบบเกม

`bash tools/check.sh` ผ่าน **23ชุด / 1,596ข้อ / 0ล้มเหลว ต่อรุ่น** รวมสองรุ่น3,192ข้อ ไม่มีSCRIPT ERROR/ERRORในผลตรวจสุดท้าย

เป็นชุดเดิม1,532ข้อ และ `test_side_guardians.gd` ใหม่64ข้อ ตรวจ:

- ภาพพิกเซล8เฟรมครบต่อออร่า ใช้ไฟล์ที่เลือก จุดกลางตา/อกจัดตรงกันระหว่างเฟรม และเฟรมเปลี่ยนจริงตามเวลา
- PHUZASHIเดิมและCHILL แสดงนินจาม่วงเมื่อได้บัฟเชียร์ หันได้ทั้งซ้าย/ขวา ใช้shader/แผ่นภาพใหม่จริง
- ล็อคขาตอนมีบัฟใช้ปีศาจนินจาแทนปีศาจเดิม คง1.1วินาที ออร่าเชียร์หมดแล้วท่าที่ร่ายไปยังเก็บค่าตอนร่าย ท่าครั้งถัดไปกลับแบบเดิม0.7วินาที และปล่อย/ลบเอฟเฟกต์เมื่อหมดล็อค
- ฟีโน่ของPHUZASHIทั้งสองแบบใช้นินจาเดียวกัน ไม่ซ้อนออร่าเชียร์อีกชุด คืนออร่าเชียร์เมื่อจบรถและบัฟยังอยู่
- BLACKแสดงปีศาจแดงหลังฟัน คง70MPและยังถูกโจมตีได้ ขอบเขตเลือด/ดาเมจ/บัฟตรวจโดยชุดBlood Pact49ข้อเดิม
- องค์พระส้มทองเริ่มระหว่างแปลง คงอยู่ร่างหัวโล้น มานา30คงเหลือจาก100ตามเดิม ซ่อนระหว่างพายุแครอทและคืนหลังจบ
- แต่ละฝั่งมีmaterial/พิกัดแผ่นภาพของตัวเอง Pauseหยุดทั้งภาพและบัฟ KO/เริ่มยกใหม่/ออกฉากล้างออร่า เปิดยก50MPเดิม

ชุดเดิมยังตรวจมานา การ์ด Perfect Guard คอมโบ อากาศ/พื้น6สกิล การดันตัว แรงถอย/สั่น คัตอิน เมนู จอยสองฝั่งและปุ่มรีแมป รวมController Parity222ข้อ, PHUZASHI CHILL76ข้อ, Blood Pact49ข้อ

## เรนเดอร์จริง

`tests/test_roster_render.gd` ผ่าน **1,096samples / 0ล้มเหลว ต่อรุ่น** รวม2,192samples ตรวจภาพไม่ว่างและไม่ชนขอบviewport ครอบคลุมตัวนักสู้/คอมโบ/ท่าเดิม ฟีโน่ทั้งสองแบบ ตัวช่วยหญิง คนอ้วนเปิดประตู และออร่าใหม่ทั้ง24เฟรมสองทิศทาง

ตรวจฉากโรงเรียนจริงทั้งหันซ้าย/ขวา ออร่าพร้อมกันสองฝั่ง ล็อคขา บัฟเชียร์ ร่างหัวโล้นและฟีโน่ พบการบวกสีทั้งภาพทำให้หน้ากากจางบนเสาสีขาว จึงเปลี่ยนเป็นalpha mixingที่รักษาเงามืดในหน้ากาก/เสื้อควันและไล่ขอบโปร่ง ย้ายข้อความเชียร์/แปลงร่างไปHUDเดิม และไม่วาดข้อความPactซ้ำทับออร่าในVersus

## ชุดดาวน์โหลด

ZIPซอร์สมีassets/scenes/scripts/tests/toolsและภาพอ้างอิงที่เกี่ยวข้อง ไม่มีEXE/PCK/cache/videoหรือZIPเก่าซ้อน ตรวจCRC/เทียบเนื้อหาทุกไฟล์ แตกใหม่เข้าGodot4.2.2 และตรวจ Blood Pact49 + PHUZASHI CHILL76 + Side Guardian64 = **189ข้อ / 0ล้มเหลว** ซ้ำ

แจกผ่านZIPของสาขาซอร์สแยกเพราะชุดรวมใหญ่กว่า100MiB และตรวจดาวน์โหลดกลับจากGitHubว่าไฟล์ตรงกับชุดที่ทดสอบ

การตรวจจอยใช้InputEventของGodot ไม่ได้จับจอยฮาร์ดแวร์ของผู้ใช้บนWindows ภาพตรวจบนLinux/OpenGL ส่วนแบบเสื้อแทร็กยังเป็นคอนเซปต์ ไม่มีท่า ตามเดิม
