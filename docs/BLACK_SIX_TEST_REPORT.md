# BLACK ครบ 6 สกิล — ผลตรวจ

Godot **4.2.2.stable / 4.6.3.stable** บน Linux ใช้ OpenGL Compatibility / Mesa llvmpipe สำหรับภาพจริง

## การทำงาน

`bash tools/check.sh` ผ่าน **27 ชุด / 2,048 ข้อ / 0 ล้มเหลว ต่อรุ่น** รวมชุดใหม่ BLACK Six Skills **187 ข้อ** และการทดสอบ PHU, ASSJIRO, มวยไทย, สัญญาเลือดเดิม, ตัวชน, จอย, เชียร์, นินจาล็อค, ฟีโน่และวาร์ปกลับ ไม่มี SCRIPT ERROR / ERROR / FAIL ในผลสุดท้าย

- ห้าสกิลแดงยืนยันการชนจริงทั้งซ้าย/ขวา: 22 / 30 / 28 / 32 / 18 ดาเมจ หักมานาครั้งเดียวและไม่มีมานาคืนแบบหมัดปกติ
- อัลติเพิ่มแรงให้แต่ละการโดนจริง: 29 / 38 / 36 / 42 / 23 ดาเมจ ทั้งสู้สองคนและเป้าสนามฝึก สัญญาณ HUD ตรงกับดาเมจที่เกิด ไม่มีบัฟซ้ำสองครั้ง
- Rage Drive ได้สามจังหวะ 8+8+14 ใช้การเคลื่อนที่ต่อเนื่อง ไม่วาร์ป และรักษาระยะตัวชน 88px ทุกเฟรม
- Hell Riser ส่งตัวฝ่ายตรงข้ามลอยในท่า FALL; Grin Crush ลดการ์ด40และทำ guard break ตามกติกากลาง Perfect Guard ยังกันได้0
- การ์ดปกติเสีย2ต่อครั้ง/6สำหรับRageครบชุด ไม่ส่งตัวที่กันสำเร็จลอย
- Outburst โดนได้ด้านหลังและผลักออกจากผู้ใช้ทั้งสองทิศ คลื่นFangมีระยะจำกัด ไม่สร้างซ้ำและหายเมื่อพลาด/KO/เปลี่ยนยก
- ตัดท่าก่อนช่วงactiveไม่มีดาเมจและไม่คืนมานา ภาพร่างพิเศษถูกซ่อนทันทีเมื่อโดนขัดหรือถูกล็อค รวมถึงระหว่างhit pause
- มานาไม่พอไม่เริ่มCD, CDป้องกันการกดซ้ำ, โดด/ถูกล็อคเริ่มท่าไม่ได้, พักเกมหยุดโปรเจกไทล์, เปลี่ยนยกล้างเอฟเฟกต์และคืน50MP
- ปุ่มจริงผ่าน InputEvent ครบทั้ง6ช่อง บนคีย์บอร์ดและจอยP1/P2 การกดของคนหนึ่งไม่สั่งอีกคน ชุดController Parityเดิมทวนปุ่มนั่งและปุ่มที่ตั้งใหม่ครบทุกตัว

แก้ fixture ใน `test_blood_pact.gd` จากห้าช่องว่างเป็นหกสกิลที่กำหนดแล้ว ยังทดสอบอัลติ70MP/เสีย20HP/บัฟ30%10วิ/หยุด1HP/ถูกรบกวน/ถูกตีตาย/คัตอินและปุ่มเดิมครบ

## ภาพ

เรนเดอร์ **1,232 samples / 0 ล้มเหลว ต่อรุ่น** รวมเอฟเฟกต์แดง20ภาพและท่าเต็มตัว16ภาพในสองทิศ ตรวจภาพไม่ว่าง/ไม่ถูกขอบviewportตัด และเพิ่มการตรวจเศษภาพแยกออกนอกเงาร่างสำหรับ32ตัวอย่างท่าร่างBLACK เพื่อจับรองเท้าจากแถวข้างเคียงโดยเฉพาะ

แก้ตัวนำเข้าAtlasTextureให้ค้นร่องโปร่งใสตามแถวที่เหลื่อมจากตาราง และจำกัดกรอบตามเงาร่างที่ต่อเนื่อง ไม่แก้PNGต้นฉบับ ใช้จุดกึ่งกลางพื้นรองเท้าจัดฐานเท้าเหมือนกัน ภาพที่ส่งเป็นคลิปบันทึกใหม่หลังแก้แล้ว

วิดีโอ Godot4.2.2 จริง 1280×720/60fps 1,093เฟรม ประมาณ18.22วินาที แสดงห้าสกิลใหม่ เขี้ยวทุบการ์ดฝั่งซ้าย คัตอินอัลติ คนอ้วนฟัน และคลื่นที่แรงขึ้นหลังบัฟ มานา100ในคลิปเป็นfixtureสาธิตเท่านั้น เกมจริงเริ่ม50
