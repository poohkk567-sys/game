# ออร่าหันข้าง — รุ่นพิกเซลที่เลือก

[ดาวน์โหลดโปรเจกต์ Godot รุ่นออร่าใหม่](https://github.com/poohkk567-sys/game/archive/refs/heads/codex/side-guardian-source.zip)
แตก ZIP ทั้งหมด → Godot4.2.2ขึ้นไป → Import `project.godot` → Import & Edit → รอนำเข้า → F5
ไม่มี EXE ใหม่ ค่าการต่อสู้และปุ่มเดิมทั้งหมด

## ออร่าใหม่ทั้งสาม

| ตัวละคร | อัตลักษณ์ | เงื่อนไขแสดง |
|---|---|---|
| PHUZASHI / PHUZASHI CHILL | **Shadow Shinobi** ปีศาจนินจาม่วง หน้ากาก ตาข้างเดียว ผ้าควันยาว ตราจันทร์/ข้าวหลามตัด โซ่เงา และท่าประสานนิ้ว | ระหว่างบัฟเชียร์ และฟีโน่อัลติ ล็อคขาขณะมีบัฟใช้ปีศาจแบบเดียวกัน |
| BLACK COAT | **Crimson Grin** ปีศาจแดงยิ้มเสี้ยวจันทร์ เขาไม่สมมาตร ปกเสื้อควัน กรงเล็บ และตรารูกุญแจพันธสัญญาที่หน้าอก | หลังคนอ้วนเปิดประตูฟันสำเร็จ จนบัฟ Blood Pact หมด |
| ASSJIRO | **Golden Lotus** องค์พระหันข้าง ฝ่ามือคุ้มกัน วงแสงบัว ตราบัวและควันส้มทอง | ค่อยปรากฏระหว่างแปลงและคงอยู่ร่างหัวโล้น ซ่อนระหว่างพายุแครอทและกลับมาหลังจบท่า |

ใช้ลายเส้นพิกเซลตามแบบที่เลือก ทั้งสามเป็นสแตนด์ออร่าพลังงานหันข้าง มีแขนและท่าทางชัด เอวสลายเป็นควัน มีแอนิเมชัน8เฟรมต่อตัว หันตามทิศนักสู้ จัดตำแหน่งด้านหลังเพื่อให้เห็นหน้า/ชุดนักสู้

ช่วงเปลวไฟและชายผ้าขยับ จุดกลางหน้ากาก/อกถูกจัดให้นิ่งเพื่อไม่กระตุกตามเฟรม มีการไล่ขอบโปร่งใสและประกายพลัง ใช้การผสมสีที่รักษาหน้ากากและลายออร่าบนฉากสว่าง ไม่มีการเปลี่ยนลายเส้นตัวนักสู้

ฟีโน่ใช้ปีศาจนินจาแทนปีศาจหน้าเดิม เมื่อมีบัฟเชียร์พร้อมกันจะแสดงปีศาจเพียงชุดเดียวระหว่างขี่รถ แล้วคืนออร่าเชียร์เมื่อจบอัลติถ้าบัฟยังอยู่ ท่าล็อคขาที่ปล่อยตอนมีบัฟยังเก็บระยะเวลา/ออร่าตามตอนร่าย แม้บัฟเชียร์หมดระหว่างล็อค การร่ายครั้งถัดไปกลับแบบปกติ

## กติกาเดิม

- เปิดยก50/100MP ชาร์จ7MP/s และ Blink5MP
- เชียร์30MP บัฟ8วินาที เคลื่อนที่+10% ล็อคขา25MP ปกติ0.7วินาที/บัฟ1.1วินาที
- ฟีโน่60MP ดาเมจ60 มีหญิงซ้อนท้าย ไฟม่วงและแรงชนเดิม
- BLACK COAT อัลติ70MP เสีย20HPใน5วินาทีไม่ต่ำกว่า1HP ตีแรง+30%10วินาที ไม่ซ้อน/ไม่อมตะ คูลดาวน์18วินาที
- ASSJIRO แปลง70MP เก็บมานาที่เหลือ รับดาเมจลด30% สกิลร่างแปลงฟรีแต่มีคูลดาวน์
- คง5ตัวเลือกเล่น การดันตัว แรงถอย/สั่น เกจป้องกัน ปุ่มจอยและการรีแมปเดิมทุกอย่าง
