# Spritesheet ปัจจุบัน / PHUZASHI

ผู้ใช้เลือกสไตล์จากชุดยืน–เดินและขอเพิ่มท่าอีกจำนวนมาก ปัจจุบันมีครบ **12 ท่า × 8 เฟรม = 96 เฟรม** และนำเข้าเล่นในฉากหลักแล้ว

เพิ่มใหม่ 5 แผ่น รวม 80 เฟรม:

- mobility.png — RUN / JUMP
- defense.png — CROUCH / GUARD
- strikes.png — PUNCH / KICK
- reactions.png — HIT / FALL
- powers.png — SPECIAL / ULTIMATE

ภาพอยู่ใน `assets/characters/spritesheets/` ส่วนยืน–เดิน 16 เฟรมแรกยังใช้ `assets/characters/drafts/idle_walk_draft.png` ภาพถูกสร้างจากแบบยืน–เดินที่ผู้ใช้เลือก โดยคงตัวละคร ชุด และรองเท้ารูปแบบเดียวกัน

## กติกาการนำเข้า

ใช้ภาพเต็มตัวทุกเฟรม ไม่ดัดข้อต่อแทนเฟรมใหม่ ไม่แบ่งแผ่นด้วยกริดเท่ากันเมื่อท่ายื่นข้ามช่อง ตัวนำเข้าตรวจ silhouette จริง จัด canvas 512×384, pivot (256,360) และเก็บภาพทั้งหมดใน SpriteFrames

ท่าล้ม 2 เฟรมมีกรอบซ้อนกับตัวข้าง ๆ จึงแยกเฉพาะพิกเซลที่เชื่อมต่อเป็นตัวนั้นแบบ lossless ไม่แก้ดีไซน์หรือวาดทับสี เอฟเฟกต์พลังยังแสดงแยกจากตัวละคร
