# ผลทดสอบจังหวะเชียร์/นินจาล็อคหลัง/พระลอยลง/ฟีโน่/ดาวกระจาย

ตรวจบนLinux ด้วย Godot **4.2.2.stable** และ **4.6.3.stable** ภาพจริงใช้ OpenGL Compatibility / Mesa llvmpipe

## ระบบเกม

ชุดรวม24ชุดผ่าน ไม่มีSCRIPT ERROR/ERROR/FAIL ในผลตรวจสุดท้าย:

- Godot4.6.3: **1,692ข้อ / 0ล้มเหลว** จาก `bash tools/check.sh`
- Godot4.2.2: ชุดรวม1,688ข้อผ่าน แล้วทวนชุดNinja Arrivalsรุ่นสุดท้าย94ข้อแทน90ข้อเดิม รวมข้อที่ตรวจไม่ซ้ำ **1,692ข้อ / 0ล้มเหลว**
- ชุดใหม่94ข้อตรวจPHUZASHIทั้งสองโปรไฟล์ สองทิศทาง ลำดับเชียร์→หายตัว→บัฟ/ควัน การพักเกม การวาร์ปที่ไม่ไหลผ่านฉาก ท่าเกาะแยกจากสแตนด์ ขนาด100/116px และหน้ากากที่ไม่ถูกตัวเป้าหมายบังมิด
- ตรวจการเลือกด้านหลังจากทิศของเป้าหมาย แม้หันหนีผู้ร่าย ระยะล็อค0.7/1.1วินาที การปล่อย/รีเซ็ต และไม่สร้างดาเมจจากท่าล็อค
- ตรวจฟีโน่60MP/60ดาเมจครั้งเดียว ส่งคู่ต่อสู้ลอย/ถอยจริง ชะลอรถไม่ข้ามร่าง การลงพื้น การ์ดไม่ลอย และปลดล็อคขาเมื่อถูกชน
- ตรวจพระไม่ขึ้นตอนหมวก/ซีอิ๊ว เริ่มตรงถอดเสื้อ ลอยลงอย่างต่อเนื่อง ถูกขัดแล้วไม่แปลง ซ่อนตอนพายุแครอทและไม่ลงซ้ำเมื่อจบพายุ คง70MP/มานาเหลือ30จาก100
- ตรวจดาวกระจายหมุนจริง ความเร็ว620px/s หยุดหมุนเมื่อPause 25MP/24ดาเมจหนึ่งครั้ง และลบหลังโดนหรือหมดอายุ เปิดยกจริง50MP

ทวนfixtureเดิมที่รอรับบัฟตอนผู้หญิงวิ่งมาถึง/พระขึ้นช่วงซีอิ๊ว ให้ตรงจังหวะใหม่ตามที่เลือก ปุ่มจอยลง+เตะยังตรงกับคีย์บอร์ดS+K ทั้งจอยปกติและรีแมป ไม่เปลี่ยนฮิตบ็อกซ์/ดาเมจดาวกระจายหรือค่าสกิลBLACK/นักมวย

## เรนเดอร์และไฟล์แจก

เรนเดอร์ชุดตัวละครเดิมพร้อมนินจาเกาะ8เฟรมสองทิศทาง **1,112samples / 0ล้มเหลว ต่อรุ่น** ตรวจภาพไม่ว่างและไม่ถูกตัดด้วยขอบviewport

บันทึกฉากจริง Godot4.2.2 ที่1280×720/60fps จำนวน1,062เฟรม ประมาณ17.7วินาที พร้อมภาพ16ภาพ ทดสอบระหว่างพัฒนาด้วยGodot4.6.3ด้วย แก้ตำแหน่งนินจาจากที่ถูกเป้าหมายบังมิดเป็นระยะ64pxด้านหลัง และปรับท่าล้มกลางอากาศหลังฟีโน่ชน

ZIPตรวจCRCและเทียบทุกไฟล์กับซอร์ส แตกเข้าโปรเจกต์ใหม่โดยไม่มีแคช Godot4.2.2 นำเข้าได้และผ่าน Blood Pact49 + PHUZASHI CHILL76 + Side Guardian64 + Ninja Arrivals94 = **283ข้อ / 0ล้มเหลว** ดาวน์โหลดกลับจากGitHubและเทียบเนื้อหาครบทุกไฟล์ก่อนส่ง

ไม่มีEXE/PCK/cache/วิดีโอหรือZIPเก่าซ้อนในชุดซอร์ส วิดีโอแยกให้ดูบนGitHub ใช้มานา100เฉพาะfixtureสาธิต ไม่เปลี่ยนค่าเปิดยก50

การตรวจจอยใช้InputEventของGodot ไม่ได้ทดสอบฮาร์ดแวร์จอยหรือWindowsของผู้ใช้ คอนเซปต์กอลิลล่าอลังการยังไม่ได้เพิ่มในเกม
