# ผลตรวจรุ่น 6 สกิล / เริ่ม 50 MP

ทดสอบด้วย Godot **4.2.2** และ **4.6.3** บน Linux โดยใช้ Compatibility renderer (Mesa llvmpipe) สำหรับตรวจภาพ และ Godot physics จริงสำหรับทดสอบต่อสู้

| ชุดตรวจ | 4.2.2 | 4.6.3 |
|---|---:|---:|
| `bash tools/check.sh` รวมระบบเดิมและใหม่ | 1,039 ข้อ ผ่าน | 1,039 ข้อ ผ่าน |
| เฉพาะ `test_six_skills.gd` (รวมอยู่ในจำนวนข้างบน) | 111 ข้อ ผ่าน | 111 ข้อ ผ่าน |
| `test_six_skill_render.gd` ภาพใหม่/แปลงร่างทุกเฟรม ทั้งสองทิศ | 96 ตัวอย่าง ผ่าน | 96 ตัวอย่าง ผ่าน |

ไม่พบ `SCRIPT ERROR`, `ERROR` หรือข้อทดสอบล้มเหลวในการรันชุดสุดท้าย

## สิ่งที่ตรวจจริง

- มานาเริ่ม 50 ของทั้งสองฝั่ง ทุกโปรไฟล์ ทุกยก และสนามฝึก อัลติเริ่มทันทีไม่ได้ ชาร์จเพิ่ม 7 MP/s ตามเดิม
- สกิลใหม่โจมตีคู่ต่อสู้จริงทั้งหันซ้ายและขวา หักมานาครั้งเดียว ไม่คืนมานาจากดาเมจสกิล และตีแต่ละเป้าหมายตามจำนวนจังหวะที่กำหนด
- รอยแยกมีเวลาเตือนและกระโดดข้ามได้จริง คูลดาวน์ห้ามใช้ซ้ำ การถูกขัดช่วงเตรียมท่าไม่ปล่อยเอฟเฟกต์ค้าง
- เงาสวนต้องรับประชิดถูกเวลา ไม่กันกระสุน และถูกโจมตีช่วงเก็บท่าได้
- เสยแครอทยกตัวคู่ต่อสู้ขึ้นด้วยความเร็วแนวตั้งจริง ไม่ใช่แค่รูปโดนตีลอย
- ASSJIRO ใส่หมวกใช้ช่องโจมตีทั้งห้าไม่ได้ แปลงร่างใช้ 100 MP มีเฟส `BLACK SOY SAUCE` และจบร่างหัวโล้นตามลำดับ
- อ้อมแขนวานรลดการเสียการ์ด 45% คงชิป 2 HP เห็นกอริลล่าขณะกันและหมดบัฟตามเวลา
- อัลติกอริลล่าเปิดโดนจึงต่อชุด รวม 60 ดาเมจ การ์ดจังหวะเปิดหยุดชุดต่อ ยืนไกลแล้วไม่โดนอัตโนมัติ
- ป้อน `InputEventJoypadMotion` จากจอยจำลองคนละ device: สติ๊กขวาของ P1/P2 ใช้สกิลคนละตัวและหักมานาแยกกัน ทดสอบปุ่ม `]` ของ P2 ด้วย input event จริง
- ค่าจอยเก่าที่เคยตั้งไว้เพิ่มช่องใหม่โดยไม่ทำให้ปุ่มซ้ำหรือทับค่าปุ่มเดิม
- การเริ่มยกใหม่ล้างกระสุน รอยแยก คูลดาวน์ บัฟ และภาพพิเศษ
- ระบบเดิม: เดิน/วิ่ง/กระโดด/หมอบ คอมโบ ตีลอย ปีศาจ ฟีโน่ ตัวช่วยเชียร์ ชาร์จ/การ์ด จอยสองฝั่ง ตั้งค่าปุ่ม เลือกตัวละคร และจบยก ผ่านชุดตรวจเดิม

## ตรวจภาพใน Godot

ภาพกอริลล่า 16 เฟรม ท่าขว้าง/หมุนเตะ 16 เฟรม และแปลงร่างซีอิ๊วดำ 16 เฟรม ตรวจด้านซ้ายและขวารวม 96 ตัวอย่าง ไม่พบตัวหายหรือขอบภาพถูกตัด แก้จุดยึดกอริลล่าให้ใช้กลางร่างเพื่อไม่ให้บางท่าเยื้องตามเท้าที่ต่ำกว่า

วิดีโอ 1280×720, 60 FPS, ประมาณ 42 วินาที แสดงทั้ง 18 ท่า บันทึกด้วย `tools/record_six_skills.gd` บน Godot 4.6.3 สคริปต์รีวิวเติมมานาก่อนสาธิตแต่ละท่าเพื่อให้ดูต่อเนื่อง เกมจริงเริ่ม 50 MP ภาพแรกของวิดีโอแสดงค่าเริ่มต้น

ภาพ PHUZASHI ต้นฉบับมี SHA-256 เดิม:
`d0d6156d5114d612c1d04e39781fcd5c783eb09b0ba1268fc8b42c9779e6be06`

ไฟล์ `.res` ใหม่สร้างด้วย Godot 4.2.2 ในโปรเจกต์นำเข้าแยก โดยไม่เขียนทับชีตฟีโน่ ท่าเดิน หรือโมเดลตัวช่วยหญิง

## ตรวจซ้ำ

```sh
bash tools/check.sh
# ตรวจภาพ ต้องใช้ display ที่รองรับ OpenGL
godot --path . --audio-driver Dummy --fixed-fps 60 --script tests/test_six_skill_render.gd
```

ตั้ง `GODOT_BIN` เพื่อเลือก Godot เวอร์ชันที่ต้องการ ผลนี้เป็นการตรวจใน Godot บน Linux; ยังไม่ได้ทดสอบกับจอยฮาร์ดแวร์จริงบน Windows รอบนี้

แพ็กซอร์สด้วย `tools/package_combo_source.py` ตรวจ CRC และเทียบข้อมูลทุกไฟล์กับต้นฉบับ พร้อม SHA-256 แยก ไม่มี EXE, PCK หรือ `.godot` cache
