# ผลตรวจสแตนด์แดชฟรี / Shadow Return / ผลักก่อนแปลง

Godot4.2.2.stable และ4.6.3.stable บนLinux ภาพจริงOpenGL Compatibility / Mesa llvmpipe

## ชุดรวม

`bash tools/check.sh` ผ่าน **26ชุด / 1,865ข้อ / 0ล้มเหลว ต่อรุ่น** ไม่มีSCRIPT ERROR/ERROR/FAILในผลตรวจสุดท้าย ชุดใหม่Shadow Return Rules103ข้อ ครอบคลุม:

- เปิดจริง50MP ไม่มีเครื่องหมายวาร์ป เมื่อไม่มีmarkปฏิเสธโดยไม่หักมานาหรือคูลดาวน์ และรหัสท่าหลุมเดิมใช้ไม่ได้
- ดาวกระจายจริงชนปกติ/การ์ด/Perfect Guardให้markครบทั้งPHUสองโมเดล ดาเมจ24/2/0ตามจริง ส่วนช่วงอมตะที่หลบได้ไม่ให้mark
- วาร์ป30MPกินmarkหนึ่งครั้ง มีภาพประสานอินก่อนย้ายตัว โผล่หลังเป้าหมายโดยมีระยะตัวชน ตี26ครั้งเดียว กลับจุดเริ่ม ไม่สร้างโปรเจกไทล์หลุม
- ไม่พอMP/ติดคูลดาวน์เก็บmarkไว้ สิทธิ์แต่ละคนไม่ปะปน วาร์ปพร้อมกันเก็บจุดเริ่มแยกกัน ถูกตีขัดหรือถูกล็อคขณะวาร์ปจะกลับโดยรับผลโจมตีตามเดิม
- ขอบสนามเลือกจุดที่ว่าง ไม่ออกนอก75..1205pxและไม่ซ้อนตัว
- สแตนด์แดชรัวที่MP0 ไม่มีคูลดาวน์ กดเตรียมแดชถัดไปได้ บัฟหมดล้างคิวและคืน5MP/0.5วินาที
- ASSร่างหมวกยังปิดสกิลแครอทอื่น แต่ช่องขวดใช้ท่าผลัก30MP/10ดาเมจ ภาพฝ่ามือเต็มตัว8เฟรม ส่งอีกฝั่งกระเด็นจริงเกิน200pxทั้งซ้าย/ขวา การ์ดเป็นchip2และไม่ลอย
- ใช้ท่าผลักแล้วแปลง70MPคงคูลดาวน์ช่องเดียวกัน พอพร้อมร่างหัวโล้นปาขวดจริงฟรีที่MP0ตามเดิม
- ปุ่มคีย์บอร์ดทั้งสองฝั่งและลง+LBบนจอยทั้งสองคน รีเซ็ต/จบยกล้างmark/ท่าวาร์ป/คิวแดชและกลับเปิด50MP

fixtureทดสอบช่องสกิลทั่วไปถูกปรับให้มีmarkเป็นเงื่อนไขเริ่ม ส่วนชุดใหม่ใช้การชนของดาวกระจายจริงเพื่อยืนยันgate ไม่เปลี่ยนการเริ่มเกมจริงให้มีmarkฟรี

## ภาพและชุดดาวน์โหลด

เรนเดอร์ทั้งชุดรวมภาพประสานอินPHUสองแบบและฝ่ามือASS24ภาพใหม่ในสองทิศ **1,160samples / 0ล้มเหลว ต่อรุ่น** ตรวจภาพไม่ว่างและไม่ถูกตัดด้วยviewport

บันทึกGodot4.2.2จริง1280×720/60fps จำนวน1,072เฟรม ประมาณ17.87วินาที แสดงดาวโดนการ์ด→mark→ประสานอิน→วาร์ปหลัง→กลับบ้าน ครบสองโมเดล แดชที่MP0 ผลัก และแปลงแล้วช่องเปลี่ยนเป็นขวด ปรับHUDให้แสดงCASTING/คูลดาวน์ระหว่างท่าอย่างถูกต้อง

ZIPตรวจCRCและเทียบทุกไฟล์กับซอร์ส แตกโปรเจกต์ใหม่ไม่มีแคช เข้าGodot4.2.2 และทวน Shadow Return Rules103 + Six Skills115 + Controller Parity223 = **441ข้อ / 0ล้มเหลว** ดาวน์โหลดกลับGitHubและเทียบทุกไฟล์ก่อนส่ง

ไม่มีEXE/PCK/cache/วิดีโอหรือZIPเก่าซ้อนในชุดซอร์ส วิดีโอ100MPและบัฟสาธิตเป็นfixtureเท่านั้น การเล่นจริงเปิด50MPและได้สแตนด์จากเชียร์ตามเดิม

จอยทดสอบด้วยInputEventในGodot ไม่ใช่ฮาร์ดแวร์ผู้ใช้บนWindows โหมดเล่นยังเป็นสองคนในเครื่องเดียว
