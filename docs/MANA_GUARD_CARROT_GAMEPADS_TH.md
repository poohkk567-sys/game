# มานา · เกจป้องกัน · สกิลแครอท · จอยสองผู้เล่น

รุ่นนี้เปิดด้วย Godot 4.2.2+ ไม่สร้าง EXE ใหม่ สนามหลักเป็นหน้าโรงเรียน มี PHUZASHI กับ RED CAP เล่นพร้อมกันคนละตัว

## เปิดเกม

แตก ZIP ทั้งหมด → Godot เลือก Import → เลือก `project.godot` → Import & Edit → รอไฟล์นำเข้า → กด F5

F6 สลับสนามต่อสู้/ฝึกเดี่ยว ในสนามฝึกกด Tab เลือกตัวละคร อ่านปุ่มได้ด้วย F1 หรือ Back/Select บนจอย

## มานา

MP เต็ม 100 และยังเริ่มยก/รีเซ็ตที่ 100 เพื่อให้ลองสกิลได้ทันที **ไม่มีการฟื้นมานาเองเมื่อยืนรอ**

| วิธีเพิ่ม | มานาที่ได้ |
| --- | ---: |
| ค้างชาร์จ: P1 Q / P2 P / จอย LT หรือ L2 | 7 ต่อวินาที |
| หมัด/เตะปกติโดนตัว รวมท่ากลางอากาศ | 3 ต่อครั้ง |
| หมัดสาม/เตะสามโดนตัว | 5 แทน 3 |
| Perfect Guard สำเร็จ | 3 |

คอมโบ JJJ หรือ KKK เข้าเป้าครบได้ 11 MP มานาไม่เกิน100 ต่อยลม ติดการ์ด โดน Perfect Guard หรือสกิลพิเศษโดน จะไม่เพิ่มมานาให้ผู้โจมตี เป้าคริสตัลในสนามฝึกให้มานาจากหมัด/เตะเช่นเดียวกัน

ชาร์จต้องยืนบนพื้น อยู่กับที่ และไม่ทำท่าอื่น ปล่อยปุ่ม เดิน กระโดด หมอบ หรือป้องกันจะยกเลิก การโจมตีขัดการชาร์จได้ ระหว่าง HIT/FALL/BOUND/GUARD BREAK/แปลงร่างชาร์จไม่ได้ หากค้างปุ่มไว้จะชาร์จต่อเมื่อกลับมาอยู่ในท่าพร้อม

## เกจป้องกัน

เกจ GUARD สีเขียวฟ้าแยกจาก MP เต็ม100 กดป้องกันค้างไม่เสียเกจเอง แต่ไม่ฟื้นขณะกดค้าง ต้องอยู่บนพื้นและหันรับคู่ต่อสู้

| การโจมตีที่รับด้วยการ์ด | เสีย GUARD |
| --- | ---: |
| หมัด1/2 หรือหมัดกลางอากาศ | 10 |
| เตะ1/2 หรือเตะกลางอากาศ | 14 |
| หมัด3 | 20 |
| เตะ3 | 24 |
| Dark Pulse หรือหัวพุ่งแครอท | 20 |
| หมัดรัวแครอท: แต่ละหมัดเบา / หมัดปิด | 4 / 12 |
| มังกรอัลติ | 40 |

รับหมัด JJJ เสีย40; เตะ KKK เสีย52; รับหมัดรัวแครอทครบเสีย36 เกจ การ์ดธรรมดามีดาเมจทะลุ2ต่อหนึ่งครั้ง

ปล่อยการ์ดและไม่โดนโจมตีครบ1วินาที เริ่มฟื้น20เกจต่อวินาที การโดนโจมตีเริ่มเวลารอใหม่ หากเกจหมดจะ **GUARD BREAK เสียหลัก1วินาที** ขยับ โจมตี กระโดด ชาร์จ และป้องกันไม่ได้ แล้วคืนเกจ50 การโจมตีที่ทำให้การ์ดแตกคิดเพียงดาเมจทะลุ2 ไม่คิดดาเมจเต็มซ้ำ หลังแตกการโจมตีถัดไปโดนเต็ม

**Perfect Guard:** เริ่มกดป้องกันก่อนรับการโจมตีภายใน0.12วินาที ไม่เสีย HP ไม่เสีย GUARD และได้3 MP พร้อมประกายสีฟ้าและเสียง หนึ่งการกดป้องกันใช้ Perfect Guard ได้หนึ่งครั้ง การกดค้างต่อจะเป็นการ์ดปกติ ไม่มีสตันอัตโนมัติให้ผู้โจมตี

## สกิล RED CAP ใหม่ — ใช้ได้ทั้งร่างสวมหมวกและร่างถอดเสื้อ

| ท่า | สนามฝึกเมื่อเลือก RED CAP | P2 บนคีย์บอร์ด | จอย | MP / ดาเมจ |
| --- | --- | --- | --- | --- |
| Carrot Headbutt กระโดดเอาหัวพุ่งพร้อมออร่าแครอทส้ม | I หรือ U | Numpad4 หรือ `'` | RT / R2 | 25 / 22 |
| Carrot Barrage หมัดรัวออร่าแครอท | S+J | ลง + Numpad1 หรือ ลง + `,` | ลง + X / Square | 30 / 6×4+8 =32 |
| Cap Off ถอดหมวก–เหยาะซอสเหลือง–ถอดเสื้อ | **O** | Numpad5 หรือ `;` | Y / Triangle | 100 / แปลงร่าง |

**I ของ RED CAP เปลี่ยนเป็นหัวพุ่งแล้ว; อัลติถอดหมวกในสนามฝึกย้ายเป็น O** ส่วน PHUZASHI ยังใช้ I เรียกมังกรตามเดิม ถ้าให้ RED CAP อยู่ช่องP1 ปุ่มเหมือนสนามฝึกคือ Iหัวพุ่ง/Oถอดหมวก

หัวพุ่งมีการกระโดดและพุ่งทางฟิสิกส์จริง สร้างความเสียหายหนึ่งครั้งต่อเป้า หมัดรัวโจมตี7จังหวะ เริ่มได้บนพื้น กดค้างไม่รัวซ้ำสกิล เมื่อโดนโจมตีหรือถูกล็อกจะยกเลิกจังหวะที่เหลือ ทั้งสองท่าถูกป้องกัน/Perfect Guard ได้ และไม่คืนมานาจากดาเมจของตัวเอง

แปลงร่างใช้เวลา3.2วินาที ถูกขัดได้และไม่คืนมานาที่ใช้ เมื่อเสร็จคงร่างจนจบยกหรือรีเซ็ต ท่าปกติและสกิลส้มยังใช้ได้ รูปลักษณ์และเอฟเฟกต์เดิมของ PHUZASHI คงเดิม

เอฟเฟกต์ใหม่มีสไปรต์ชีตโปร่งใส 2 แผ่น แผ่นละ16เฟรม:

- `assets/effects/carrot_headbutt_vfx.png`
- `assets/effects/carrot_barrage_vfx.png`

ท่าตัวละครใช้ภาพเต็มตัวเดิม: หัวพุ่งใช้ภาพวิ่งพร้อมเอนทั้งตัว ส่วนหมัดรัวสลับภาพหมัดและหมัดปิด ไม่ตัดตัวละครเป็นชิ้นส่วน

## เล่นด้วยจอย

ใช้จอยที่ระบบปฏิบัติการและ Godot ตรวจพบ เช่น Xbox หรือ PlayStation ต่อ USB/Bluetooth ตามระบบปฏิบัติการก่อนเปิดเกม หรือเสียบระหว่างเล่นได้

- **จอยหนึ่งอัน:** ควบคุม P2; อีกคนใช้คีย์บอร์ด P1 กด **F5** สลับจอยไป P1 ได้ เกมหยุดให้ตรวจฝั่งก่อน กด Start เล่นต่อ
- **จอยสองอัน:** แยกควบคุม P1/P2 ตามหมายเลขอุปกรณ์ของ Godot ดูสถานะ PAD1/PAD2 เหนือสนาม คีย์บอร์ดของแต่ละฝั่งยังใช้ร่วมได้
- **สนามฝึกเดี่ยว:** จอยแรกควบคุมตัวที่เลือกอยู่
- เมื่อจอยถูกเสียบ/ถอดหรือหน้าต่างเสียโฟกัส เกมหยุดและปล่อยปุ่มค้าง ตรวจฝั่งให้ถูกก่อนกด Start/Esc เล่นต่อ หลังพักหรือเปลี่ยนอุปกรณ์ต้องปล่อยสติ๊ก/ปุ่ม/ทริกเกอร์กลับกลางก่อนใช้อีกครั้ง

| Xbox | PlayStation | การทำงาน |
| --- | --- | --- |
| สติ๊กซ้าย / D-pad ซ้ายขวา | เหมือนกัน | เดิน; แตะทิศสองครั้งเป็น Blink สำหรับ PHUZASHI |
| A / D-pad ขึ้น | Cross / D-pad ขึ้น | กระโดด |
| สติ๊กซ้ายลง / D-pad ลง | เหมือนกัน | หมอบ |
| X | Square | ต่อย; แตะ3ครั้งเป็นคอมโบ |
| B | Circle | เตะ; แตะ3ครั้งเป็นคอมโบ |
| LB | L1 | ป้องกัน / Perfect Guard |
| RB | R1 | วิ่งร่วมกับทิศทาง |
| LT | L2 | ค้างชาร์จมานา |
| RT | R2 | PHUZASHI Dark Pulse / RED CAP หัวพุ่งแครอท |
| Y | Triangle | PHUZASHI มังกร / RED CAP ถอดหมวก |
| ลง + X | ลง + Square | PHUZASHI ปีศาจล็อก / RED CAP หมัดรัวแครอท |
| Start | Options | หยุด/เล่นต่อ; เมื่อจบแมตช์กดเพื่อเริ่มใหม่ |
| Back | Select / Share | เปิด/ปิดรายการปุ่ม |
| Y ขณะเกมพัก | Triangle ขณะเกมพัก | เริ่มแมตช์ใหม่ |
