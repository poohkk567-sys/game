# สนามหน้าโรงเรียน

`school_gate.png` เป็นภาพพิกเซลอาร์ตสร้างจากภาพอ้างอิงหน้าโรงเรียนที่ผู้ใช้ส่ง มีป้ายดำขอบทอง เสาสีขาวพร้อมโคมกลม อาคารเรียน พุ่มไม้ ต้นไม้ สายไฟ และท้องฟ้าเย็นสีทอง
ป้ายใน PNG เว้นว่าง และ `scripts/stage/school_art.gd` วาดชื่อโรงเรียนภาษาไทย/อังกฤษด้วย font จริงเพื่อให้อ่านได้ถูกต้อง ตัดข้อความซ้อนจากโพสต์ต้นทางออก

ภาพวาด1280×720ในเกม ทางเดินแนวราบจริงที่ y586 ตรงกับ collider เดิม ตัวละครทั้งสองเคลื่อนที่ด้านข้าง
ฟอนต์ Noto Sans Thai ใช้แสดงภาษาไทย เก็บไฟล์ใบอนุญาตไว้ใน `assets/fonts/NOTO_LICENSE.txt`
