# RED CAP — ท่าปกติ

ตัวละครพิกเซลอาร์ตทรงเดียวกับ PHUZASHI ใช้หมวกแดง เสื้อแขนยาวขาวลายดำ กระเป๋าดำ กางเกงดำ และรองเท้าดำปลาย/พื้นสีครีม
**ไม่มีผม** ทั้งหน้าผาก ขมับ และท้ายทอย ให้เห็นผิวใต้หมวกในทุกเฟรม อ้างอิง `design_reference.png`

แต่ละแผ่นโปร่งใสเรียง 4 คอลัมน์ × 4 แถว อ่านซ้ายไปขวา แถวบนสองแถวเป็นท่าแรก 8 เฟรม แถวล่างสองแถวเป็นท่าที่สอง 8 เฟรม

| ไฟล์ | 8 เฟรมบน | 8 เฟรมล่าง |
| --- | --- | --- |
| idle_walk.png | IDLE ยืน | WALK เดิน |
| run_jump.png | RUN วิ่ง | JUMP กระโดด |
| crouch_guard.png | CROUCH หมอบ | GUARD ป้องกัน |
| punch_kick.png | PUNCH หมัดตรง | KICK เตะตรง |
| punch_combo.png | PUNCH_2 หมัดฮุก | PUNCH_3 อัปเปอร์คัต |
| kick_combo.png | KICK_2 เตะหมุน | KICK_3 เตะสับ |
| hit_fall.png | HIT โดนโจมตี | FALL ล้ม |

รวม 14 ท่า / 112 ภาพเต็มตัว ภาพกระโดดต่อยและกระโดดเตะใช้ภาพ PUNCH/KICK ของตัวนี้กับฟิสิกส์กลางอากาศ จึงเล่นได้ 16 สถานะท่าปกติ สถานะ BOUND ใช้ HIT ค้างเมื่อถูกล็อก
ยังไม่มีภาพหรือสกิลพิเศษของตัวใหม่นี้ และหมัดที่สามไม่มีพลังม่วงของ PHUZASHI

`red_cap_frames.res` เป็น SpriteFrames สำหรับ Godot 4.2.2+ ใช้ AtlasTexture จากภาพต้นฉบับ ไม่มีการแยกแขนขาหรือดัด mesh `manifest.json` บันทึกพื้นที่แต่ละรูป จุดรองเท้า พื้น y และสเกลต่อท่า
แคนวาสเสมือน 1024×1024 จุดอ้างอิง (512,960) ขนาดยืนในเกมประมาณ 156 พิกเซล สเกลคงที่ภายในท่าเพื่อรักษาการหมอบ/ล้มจริง

สร้าง resource ใหม่ด้วย Godot **4.2.2** เพื่อรักษาความเข้ากันได้:

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tools/import_red_cap_sprites.gd
```

นำทั้งโฟลเดอร์ไปไว้ `res://assets/characters/red_cap/` และ Import ภาพก่อนโหลด .res
