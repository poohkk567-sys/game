# Complete hand-seal and capped palm-shove drawings

Three preserved transparent4×2 source sheets,8 full-body frames each:

- seal_chill.png: redesigned PHUZASHI CHILL, white-soled shoes and skull/striped outfit.
- seal_classic.png: original clear PHUZASHI, earbud cord, sling bag and cream-toe shoes.
- capped_shove.png: capped/clothed ASSJIRO, two open palms, no awakened artwork.

Regenerate cast_frames.res with Godot4.2.2 using tools/import_ninja_cast.gd after PNG import. The importer fits transparent gutters and aligns the feet on the virtual1024×1024 canvas/pivot512,960. Sources are unchanged; the existing alpha-cutout shader trims faint generated haze at render time. Each pose renders at156px height. Normal fighter banks, faces and clothing remain separate and unchanged.
