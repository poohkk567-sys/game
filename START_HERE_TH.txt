2. เปิด Godot4.2.2+ → Import → เลือก project.godot → Import & Edit
3. รอนำเข้าไฟล์ แล้วกด F5
4. เลือกตัวละครของ P1/P2: PHUZASHI / ASSJIRO / MUAY THAI
5. กดเริ่มต่อสู้สองผู้เล่น หรือสนามฝึกด้วยตัวที่เลือกP1
