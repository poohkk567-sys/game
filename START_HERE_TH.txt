PHUZASHI — DARK PULSE / PHUZASHI CHILL + BLACK COAT และออร่าผู้พิทักษ์

แตก ZIP ทั้งหมด → Godot4.2.2+ → Import project.godot → Import & Edit → รอนำเข้า → F5
เลือกตัวละคร P1/P2 แล้วสู้สองคนหรือฝึกเดี่ยว เริ่มทุกยก 50/100 มานา

P1: A/D เดิน Shift วิ่ง Space/W กระโดด S หมอบ J/K ต่อยเตะ L กัน Q ชาร์จ E แดช
สกิล: U / S+J / S+K / S+L / S+Shift / I อัลติ
ASSJIRO ใช้ I หรือ U หัวพุ่ง และ O แปลงร่าง

P2: ลูกศรเดิน/กระโดด/นั่ง Ctrl วิ่ง Num1/2/3 หรือ , . / ต่อยเตะกัน P ชาร์จ Num0 หรือ \ แดช
สกิล: Num4 หรือ ' / ลง+Num1 / ลง+Num2 / ลง+Num3 / ลง+Ctrl / Num5 หรือ ; อัลติ
ใช้ , . / แทน Num1/2/3 ในปุ่มสกิลนั่งได้

จอย: A กระโดด X ต่อย B เตะ LB กัน RB วิ่ง LT ชาร์จ L3 แดช
สกิล: RT / ลง+X / ลง+B / ลง+LB / ลง+RB / Y อัลติ
กดนั่งค้างก่อนแล้วกดปุ่มท่า ลง+เตะตรงกับ S+K (PHUZASHI เชียร์) ค้างปุ่มไม่รัวสกิล
F7/R3 ตั้งจอย1 จอย2 และปุ่มเองได้ สกิลนั่งตามปุ่มต่อย/เตะ/ป้องกัน/วิ่งที่ตั้งไว้
ทางลัด T/Y/F, Dpadขึ้น และสติ๊กขวาเดิมเลิกใช้ตามค่าเริ่มต้น

ASSJIRO แปลงร่างใช้70 MP เก็บมานาที่เหลือ หลังแปลงใช้สกิลทั้ง5ไม่เสียมานาแต่มีคูลดาวน์
พายุแครอทแทนตัวคนและอมตะเฉพาะระหว่างใช้ จบแล้วโดนโจมตีได้เหมือนเดิม
PHUZASHI Blink ใช้5 MP ฟีโน่มีหญิงซ้อนท้าย ไฟและปีศาจม่วง อัลติทุกตัวมีคัตอินด้านซ้าย
มวยไทยมีท่ายืน/แดชใหม่ เคลื่อนที่ต่อเนื่อง ไม่มีอมตะแดช
เดินชนแล้วดัน ติดขอบหยุด โดนโจมตีสั่นและถอยตามน้ำหนักท่า

F1 ดูปุ่ม F7 ตั้งจอย F8 หน้าแรก Esc/Start พัก R เริ่มใหม่ Tab สลับตัวในสนามฝึก
