PHUZASHI — DARK PULSE / กระโดดโจมตีและคอมโบ 3 จังหวะ

1. แตก ZIP ทั้งหมดก่อน
2. เปิด Godot 4.2.2 หรือใหม่กว่า (แนะนำ Godot 4.6.3)
3. เลือก Import แล้วเลือก project.godot ในโฟลเดอร์นี้
4. กด Import & Edit รอโปรแกรมนำเข้าไฟล์ แล้วกด F5 เล่น

แตะ A สองครั้ง = Shadow Blink ไปซ้าย
แตะ D สองครั้ง = Shadow Blink ไปขวา
ต้องแตะสองครั้งภายใน 0.28 วินาที ใช้ MP 15 ต่อครั้ง

A/D หรือปุ่มลูกศร = เดิน | Shift = วิ่ง | Space = กระโดด
Space + J = กระโดดต่อย | Space + K = กระโดดเตะ
กระโดดก่อนแล้วกด J/K กลางอากาศก็ได้ ยังใช้ A/D ควบคุมทิศทางได้
J–J–J = คอมโบต่อย 3 จังหวะ ดาเมจ 8 + 10 + 16
K–K–K = คอมโบเตะ 3 จังหวะ ดาเมจ 14 + 16 + 22
กด 3 ครั้งติดกันได้ เกมจำจังหวะที่กดล่วงหน้าไว้ให้
กดค้างอย่างเดียวจะออกท่าเดียว ไม่ต่อคอมโบอัตโนมัติ
S = หมอบ | L = ป้องกัน
U = Dark Pulse | I = มังกร Ultimate
R = รีเซ็ต HP/MP คอมโบ และเอฟเฟกต์ | Esc = หยุด/เล่นต่อ
F1 = ดูปุ่ม | F2 = สาธิตท่าหลัก กระโดดโจมตี คอมโบ และ Shadow Blink

ยังมีเอฟเฟกต์ Shadow Blink ชุดที่เลือกไว้ พร้อมเงาและรอยแยกพลังม่วง
ไม่มี EXE ในชุดนี้ ต้องเปิดเล่นผ่าน Godot
