# PHUZASHI — DARK PULSE / คู่มือภาษาไทย

[ดาวน์โหลดโปรเจกต์ Godot ล่าสุด](https://github.com/poohkk567-sys/game/archive/refs/heads/codex/blood-pact-source.zip)

แตก ZIP ทั้งหมด → เปิด Godot4.2.2ขึ้นไป → Import `project.godot` → Import & Edit → รอนำเข้า → F5

เลือกเล่น PHUZASHI / PHUZASHI CHILL / ASSJIRO / MUAY THAI / BLACK COAT ได้ทั้งสองฝั่ง หรือเลือกสนามฝึกเดี่ยว ไม่มี EXE ใหม่

- PHUZASHI CHILL เป็นตัวใหม่ครบทุกท่า ต่อยและคอมโบสามครั้งแบบชิล สกิล/มานา/ดาเมจเหมือน PHUZASHI เดิม
- BLACK COAT มีท่าพื้นฐานครบกับอัลติคนอ้วนเปิดประตูมาฟันตัวเอง ใช้70MP เสีย20HPใน5วิไม่ต่ำกว่า1HP แลกตีแรงขึ้น30%นาน10วิ มีปีศาจยิ้มแดง
- PHUZASHI ได้บัฟเชียร์มีออร่าปีศาจม่วงและล็อคขาอลังการ ASSJIRO แปลงร่างมีองค์พระ/วงแสงส้มทอง
- แบบเสื้อแทร็กดำ–ทองอยู่ `docs/concepts/track_jacket_neutral.png` เป็นคอนเซปต์สูงเท่าASSJIRO ยังไม่ทำท่า
