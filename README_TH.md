# PHUZASHI — DARK PULSE / Prototype 01

โปรเจกต์ Godot 4.2+ สำหรับ **ตัวละคร PHUZASHI เพียงตัวเดียว** (Training Ground) ใช้ Master Sprite PNG ต้นฉบับตามไฟล์ที่ผู้ใช้ส่งมา **โดยไม่แก้ไขพิกเซลของตัวละคร**

## วิธีเปิดโปรเจกต์
1. ติดตั้ง **Godot Engine 4.2 หรือใหม่กว่า** (แนะนำเวอร์ชัน 4.x ปัจจุบัน)
2. เปิด Godot > **Import** > เลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
3. กด **F6** (ฉากปัจจุบัน) หรือ **F5** (เล่นทั้งโปรเจกต์)

หรือทดสอบแบบไม่ติดตั้ง Godot โดยเปิด `browser/PHUZASHI_Playable_Demo.html` บน Chrome/Edge

## สิ่งที่ทำแล้ว
- โครงสร้าง Godot ที่แยก Player scene, Player script, Training scene, Training script
- รูปตัวละครจริงในไฟล์ 64 × 64 px พื้นหลังโปร่งใส วาดแบบ Pixel Perfect (Nearest)
- ฟิสิกส์เดิน วิ่ง กระโดด หันหน้าและชนพื้นจริง; กล้องแบบฉากเดียว
- State สำหรับ IDLE/WALK/RUN/JUMP/FALL/CROUCH/GUARD/PUNCH/KICK/SPECIAL/ULTIMATE
- HUD: HP, MP, ชื่อและสถานะตัวละคร
- ฉากภูเขา ทุ่งหญ้า และลานฝึกวาดด้วยโค้ด

## ข้อจำกัดสำคัญ
- ไฟล์ Master Sprite เป็น **เพียง 1 เฟรม** ไม่ใช่ sprite sheet: จึงยังไม่มีแอนิเมชันเดิน/วิ่ง/ต่อย/เตะ ที่ขยับอวัยวะทีละเฟรมจริง
- Idle/Walk/Run ใช้การขยับตำแหน่งรูปเล็กน้อยเพื่อทดสอบระบบชั่วคราว
- Punch/Kick/Special/Ultimate เป็นเพียง **เอฟเฟกต์ต้นแบบ** ไม่ใช่ท่าที่อนิเมตสมบูรณ์ และ **ยังไม่มีระบบสร้างความเสียหาย** เพราะโปรเจกต์นี้มีตัวละครเดียว
- สถานะหมอบและป้องกันยังเป็นต้นแบบ ยังไม่มี Sprite ท่าหมอบ/ป้องกัน
- ยังไม่ได้รัน Godot ภายในสภาพแวดล้อมที่จัดทำไฟล์ จึงควรทดสอบ F5 ในเครื่องของคุณ
